# עט אדום (Red Pen)

Phone-first PDF markup: mark areas or points on a PDF, write what to change, and share a structured note plus numbered page images with an AI assistant.

Single static page (`index.html`) with pdf.js vendored in `vendor/`. Installable as a PWA (`manifest.webmanifest`, `sw.js`). No server, no accounts; markers are stored in the browser's localStorage.
